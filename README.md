# ammar-ai-video-studio
AI-powered video production studio for Arabic cinematic videos.

## KHAYBAR 2.0 brand identity
- Final logo: `brand/logo/` — see `docs/logo-final.md`
- Design tokens: `brand/design-tokens/tokens.json`
- Review page: open `showcase/logo/index.html` in a browser
- Regenerate: `python3 scripts/build_logo.py && python3 scripts/qa_logo.py && node scripts/export_logo.js && python3 scripts/build_showcase_logo.py`
- Outro video (Remotion): `exports/video/khaybar-outro.mp4` — see `docs/outro.md`
- Claude skill: `skills/khaybar-brand/` (upload `exports/khaybar-brand-skill.zip`)
